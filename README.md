# لجنة المقابلة الذكية | SDAIA Academy

مشروع محاكاة مقابلات عمل متعددة الوكلاء، مُعدّ للتقديم إلى **SDAIA Academy**.

## فكرة المشروع

تقرأ ريم السيرة الذاتية وتستخرج بيانات المرشح، ثم تدير نورة مقابلة تخصصية باللغة الإنجليزية، ومازن مقابلة موارد بشرية باللغة العربية. بعد الإجابات، تراجع لينا الأداء وفق مؤشرات واضحة، ويلخص راشد نقاط القوة ومجالات التحسين المدعومة بالإجابات.

## تشغيل المشروع في VS Code

1. افتح مجلد المشروع في VS Code.
2. افتح القائمة **Terminal → Run Task…**.
3. اختر **تشغيل المقابلة محليًا**.
4. ستفتح الواجهة في المتصفح على `http://127.0.0.1:4174/` (إذا كان المنفذ مشغولًا سيختار الخادم المنفذ التالي ويطبع العنوان في الطرفية).

يتطلب التشغيل Node.js. الواجهة والباك إند يعملان على جهازك على `127.0.0.1` فقط، ولا يحتاج المشروع إلى قاعدة بيانات أو مفتاح API.

## الباك إند المحلي

- `GET /api/health` للتأكد من أن الخدمة تعمل.
- `POST /api/cv/analyze` لتحليل نص السيرة وإرجاع ملف المرشح.
- `POST /api/interviews` لإنشاء جلسة وأسئلتها بناءً على التخصص والسيرة.
- `POST /api/interviews/:id/answers` لحفظ إجابة واحدة، تقييمها، وإرجاع السؤال التالي أو التقرير النهائي.

تُستخرج نصوص PDF وWord في المتصفح باستخدام مكتبات عبر CDN، ثم يُرسل النص إلى الخادم المحلي فقط. الخادم يحتفظ ببيانات الجلسة والإجابات مؤقتًا في ذاكرة الجهاز، ويحذف الجلسة بعد إصدار التقرير؛ إعادة تشغيل الخادم تنهي كل الجلسات المفتوحة. لا تُرسل السيرة إلى خدمة خارجية. لا يتضمن المشروع OCR للسير المصورة.

## ملاحظات

- أسئلة التخصص باللغة الإنجليزية، وأسئلة الموارد البشرية والتقييم باللغة العربية.
- ملفات السيرة المدعومة: PDF النصي وDOCX وTXT وMarkdown.
- هذا نموذج أولي يستخدم قواعد محلية لاستخراج المعلومات وتقييم الإجابات، وليس خدمة توظيف أو حكمًا نهائيًا على المرشح.
